# Netlify City — Multiplayer

Multiplayer city builder & stock market game.

## Setup

1. Connect this repo to the Netlify site `netlify-city-game` (or create a new site from this repo).
2. Install the **Neon** extension (powers Netlify DB) on the site — or set env var `NETLIFY_DB_URL` / `DATABASE_URL` to a Postgres connection string.
3. Set environment variable `JWT_SECRET` to any long random string.
4. Trigger a deploy.

**Admin**: register with username `sidd` and password `deepsidd`.

New accounts start with **$1,000** and a fresh city.
